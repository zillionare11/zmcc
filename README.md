# 看看 · Kan Kan

一个单文件的股票持仓台账 + 每日复盘工具。打开 `index.html` 即可使用，无需安装、无需后端、零依赖。

数据只保存在你自己的浏览器里，不上传任何服务器。

## 功能

**首页 · 持仓**

- 顶部汇总：持仓笔数、总市值、浮动盈亏、今日盈亏

- 每笔持仓卡片：成本价、现价、浮动盈亏、回本进度条、今日涨跌

- 今日表现卡片：列出每只持仓的今日涨跌与今日盈亏，并按日 K 线的均线和近 20 日高低点，给出对未来几日走势的简评（含支撑位与压力位）

**台账 · 记录**

- 新建 / 编辑 / 删除记录，支持按名称、代码搜索

- 筛选：全部、持仓、已离场、已回本

- 离场价格、收盘快照（按日记录收盘价，作为价格历史，不影响回本计算）

**复盘记录**

- 按日期填写复盘内容，可手改日期

- 记录按日期倒序展示，支持单条删除

- 一键导出 Markdown（`kankan-review-日期.md`），方便归档或转存到笔记软件

**行情**

- 报价与日 K 线来自东方财富公开接口（JSONP）

- 手动「刷新行情」，以及 A 股交易时段内每 15 分钟自动刷新（9:25–11:32、12:58–15:02）

- 15:00 之后首次打开会自动给每笔持仓写入当日收盘价（同一天只写一次）

**其他**

- 深色 / 浅色主题一键切换，偏好本地记忆

- 键盘快捷键：`/` 聚焦搜索，`Esc` 关闭面板，保存复盘支持 `⌘ / Ctrl + Enter`

## 快速开始

方式一：直接用浏览器打开 `index.html`。

方式二：部署到 GitHub Pages 后访问

```
https://<你的用户名>.github.io/kankan/
```

## 部署到 GitHub Pages

1. 新建公开仓库 `kankan`
2. 把 `index.html`、`README.md`、`.nojekyll` 上传到仓库根目录
3. 进入 **Settings → Pages**，Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存
4. 等 1–2 分钟，即可通过上面的链接访问

`.nojekyll` 用于跳过 Jekyll 处理，空文件即可。

## 数据与备份

所有数据保存在浏览器 localStorage：

| 键名                           | 内容               |
| ---------------------------- | ---------------- |
| `position-ledger.v1`         | 持仓记录（含行情、日 K 缓存） |
| `position-ledger.reviews.v1` | 复盘记录             |
| `ledger.theme`               | 主题偏好             |

因此：

- 换设备、换浏览器、清缓存或使用无痕模式，数据都不会跟过去

- 备份请用台账页底部的「导出 JSON」（含持仓与复盘，可再导入）

- 只想归档复盘文字，用复盘卡片右上角的「导出复盘」

## 字段说明

新建记录时可以填写：

- **名称 / 代码**：代码支持 `600089`、`600089.SH`、`000001.SZ`、`00700.HK`、`AAPL` 等写法，用于拉取行情

- **买入日期 / 买入价 / 股数**：股数留空时，盈亏按每股估算，不计入市值汇总

- **离场价**：标记已离场后按离场价计算盈亏

## 技术与限制

- 单文件 HTML（HTML + CSS + 原生 JS），无框架、无构建步骤

- 行情与日 K 依赖第三方公开接口，网络不通或接口变动时会显示「等待刷新 / 暂无数据」

- 走势点评是基于均线与近期高低点的规则化推演，**仅供参考，不构成投资建议**
